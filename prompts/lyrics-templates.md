# 歌词结构模板

ACE-Step 对 `[verse]` `[chorus]` `[bridge]` 这种段落标签响应很好，纯文本歌词容易跑偏。

## 标准流行歌结构 (2-3 分钟)

```
[verse]
<第一段主歌 4-8 行，铺陈背景或情绪>

[chorus]
<副歌 4 行，要简洁有 hook，能跟唱>

[verse]
<第二段主歌，推进情绪或叙事>

[chorus]
<副歌重复>

[bridge]
<桥段 2-4 行，情绪转折，可以换调或换节奏>

[chorus]
<副歌再来，通常更高潮、加叠加>
```

## 极简结构 (60-90 秒短歌，社交媒体用)

```
[verse]
<4 行>

[chorus]
<4 行>

[chorus]
<4 行，可以重复或叠加变奏>
```

## 节奏感强的版本 (流行/EDM/Trap)

```
[intro]
<2-4 行起调，或者纯器乐>

[verse]
<4 行>

[pre-chorus]
<2-4 行，张力递增>

[chorus]
<4 行 hook>

[verse]
<4 行>

[pre-chorus]
<2-4 行>

[chorus]
<hook 重复>

[drop]
<纯器乐段或 ad-lib>

[chorus]
<最后一次 hook>
```

## 段落标签速查

| 标签 | 用途 |
|---|---|
| `[intro]` | 前奏，可空段或填器乐描述 |
| `[verse]` | 主歌 |
| `[pre-chorus]` | 预副歌，张力递增 |
| `[chorus]` | 副歌（hook 所在） |
| `[bridge]` | 桥段，情绪转折 |
| `[hook]` | 钩子段（嘻哈常用） |
| `[break]` | 间奏 |
| `[drop]` | EDM 的 drop |
| `[outro]` | 尾奏 |

## 中文歌词技巧

- ACE-Step 中文支持还行，但**对粤语/方言不稳定**
- **押韵不强求**，模型不会因为不押韵就跑调；情绪准确比押韵更重要
- **字数对齐**比押韵更重要，主歌每行字数尽量接近
- 避免太多生僻字，模型发音可能会怪
- 中英混搭也能跑，但建议主歌纯中文、副歌或 hook 加英文，效果较稳定

## 提示词配合

歌词里别写风格，风格放在 style/tags 栏。歌词只管内容和段落结构。
